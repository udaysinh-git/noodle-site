FAQ

FAQ

Short answers about Noodle.

Is Noodle free?

Yes. Noodle is free to download and use, with no paid tier and no account.

Is Noodle open source?

Yes. The source code is on GitHub under the GNU AGPL 3.0, with an added permission described in the NOTICE file.

Does Noodle collect any data?

No. There is no telemetry, no analytics, no crash reporting and no account. The only requests Noodle makes on its own are plain downloads: the ad blocking filter lists and update checks for the userscripts you installed, once a day, and site icons without cookies.

Does Noodle block ads?

Yes. Ad and tracker blocking is on from the first start, with filter lists updated daily. Third-party cookies, Privacy Sandbox ad APIs, link auditing pings and WebRTC local address leaks are blocked or turned off by default too.

Which platforms does Noodle run on?

Windows now. macOS and Linux later.

How is Noodle different from Chrome?

Noodle uses the same Chromium engine, so sites work the same. It adds vertical tabs in spaces, split view, a canvas board per space, built-in ad blocking, a media player for old video formats and full window skins, and it keeps your profile encrypted on your disk. The comparison page goes row by row.

How is Noodle different from Arc or Zen?

Like Arc and Zen, Noodle is built around a vertical sidebar and spaces. Unlike Arc it is open source and blocks ads by default, and unlike Zen it runs on Chromium. See Noodle compared.

Can AI agents use Noodle?

Yes. Noodle has a built-in MCP server that agents connect to. It is off until you turn it on, listens only on 127.0.0.1 and needs a token. Purchases, sending messages and similar actions stop at an approval card, and one shortcut stops every agent. The agent guide explains the setup.

Do Chrome extensions work?

Noodle runs Tampermonkey and Violentmonkey userscripts natively, without an extension. See the userscript guide.

When can I download it?

Noodle 0.1.0 launches on Thursday 5 November 2026 at 6:00 PM India time. The download page switches on at that moment.

Why does Windows warn about the installer?

The installer isn't code signed yet, so SmartScreen says it comes from an unknown publisher. Click "More info", then "Run anyway". Signing is planned.
