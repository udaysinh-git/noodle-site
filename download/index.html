Installing

The installer isn't code signed yet, so Windows SmartScreen will warn that it comes from an unknown publisher. Signing is planned.

  1. Download the installerFrom 5 November, the button above points at the newest release.
  2. Run itIf SmartScreen stops it, click "More info", then "Run anyway".
  3. Pick a folderChoose where Noodle goes, and it's ready. Ad blocking is already on.

Or build it yourself

You need Node.js 22.12 or newer and Git.

git clone https://github.com/udaysinh-git/noodle.git
cd noodle
npm ci
npm run dist

The installer lands in dist/. The developers page has the details.
